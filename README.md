## Selected Projects

### 🌿 Daun — Carbon-Aware AI Prompting
*Quantifying the ecological footprint of your AI, in real time, where you actually type.*

A lightweight tool suite that makes LLM usage transparent by converting prompts into cost and environmental signals: **Prompt → Tokens → API Cost → Energy → CO₂**.

- Chrome extension injecting a live token/cost/CO₂ HUD into ChatGPT, Claude, and Gemini
- Web calculator for estimating prompt cost and carbon impact before you send
- Prompt efficiency analyser with inline rewrite suggestions to reduce token waste
- Usage telemetry pipeline → Supabase, powering per-user AI FinOps dashboards
- Built with TypeScript · Vanilla JS (Manifest V3) · Supabase (PostgreSQL) · Vite · React

Repo: https://github.com/LeJ7-commits/daun  
Live demo: https://ibudaun.lovable.app/
